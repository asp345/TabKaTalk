# KakaoTalkTablet

## What is it?
KakaoTalkTablet is a LSPosed/Xposed module that enables tablet mode (2-device) support on KakaoTalk app.

## How to install
### Prerequisites
To use this module you must have following installed:
- [Magisk](https://github.com/topjohnwu/Magisk) / [KernelSU](https://github.com/tiann/KernelSU) / [APatch](https://github.com/bmax121/APatch)
- Zygisk (Enable in magisk app or use other implementations like [ReZygisk](https://github.com/PerformanC/ReZygisk))
- [LSPosed](https://github.com/LSPosed/LSPosed) (Tested on [JingMatrix's fork](https://github.com/JingMatrix/LSPosed))

### Installation
- Download the latest APK of KakaoTalkTablet from the [releases section](https://github.com/asp345/TabKaTalk/releases) and install it like any normal APK.
- Now open the LSPosed Manager and go to "Modules".
- KakaoTalkTablet should now appear in that list.
- Click on KakaoTalkTablet and enable the module by flipping the switch at the top that says "Enable module".
- Next, tick KakaoTalk app (or any apps that you want to spoof details for) and reboot your phone afterwards.
- Once rebooted, delete the app data of KakaoTalk and launch it.
